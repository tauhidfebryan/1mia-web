# 1MIA Web - Website Resmi Kelas 1MIA

Website resmi untuk kelas **1MIA (Manajemen Informatika)**. Website ini berfungsi sebagai pusat informasi, jadwal pelajaran, galeri kegiatan, serta struktur organisasi kelas.

---

## Fitur Utama

- **Beranda:** Halaman utama dengan antarmuka yang modern dan responsif.
- **Struktur Organisasi:** Menampilkan daftar pengurus kelas beserta peran masing-masing.
- **Galeri:** Dokumentasi foto dan momen kegiatan kelas.
- **Jadwal:** Informasi jadwal kuliah/pelajaran dan kegiatan harian kelas.

---

## Teknologi yang Pengurus Gunakan

- **Framework:** [Next.js](https://nextjs.org/) (React Framework)
- **Bahasa Pemrograman:** TypeScript / JavaScript
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Font:** Poppins (via `next/font/google`)
- **Deployment:** Vercel / GitHub Pages
